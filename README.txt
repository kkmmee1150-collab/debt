อัปเดตแอป (ทำทุกครั้งที่ได้ไฟล์ใหม่)
1) GitHub > repository debt > Add file > Upload files
2) ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html, config.js, sw.js, manifest.webmanifest, icon-192.png, icon-512.png) แล้ว Commit
3) รอ 1-2 นาที แล้วเปิดแอปใหม่ 1-2 รอบ

เชื่อมชีต (ทำครั้งเดียว)
1) เปิด Google Sheet > ส่วนขยาย > Apps Script > วางโค้ดจาก sheet-script.gs ทับของเดิม แล้วกดบันทึก
2) ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > ไอคอนดินสอ > เวอร์ชัน: เวอร์ชันใหม่ > ทำให้ใช้งานได้ (URL เดิมไม่เปลี่ยน)
3) ลิงก์และรหัสลับอยู่ในไฟล์ config.js แล้ว ทุกเครื่องใช้ค่านี้อัตโนมัติ

ข้อควรระวัง: config.js อยู่ใน repository สาธารณะ ใครรู้ที่อยู่ไฟล์จะเห็นรหัสได้ ไม่ควรใช้เบอร์โทรหรือรหัสที่ใช้ที่อื่นเป็นรหัสลับ

อัปเดตสแกนสลิป (v12)
- อ่านด้วย OCR ในเครื่อง + กฎโค้ด ไม่ใช้ AI (ตั้งค่า > สแกนสลิป เลือกได้ว่าจะใช้ Claude หรือไม่)
- จดให้: จำนวนเงิน วันที่ เวลา จ่ายให้ใคร ค่าอะไร(บันทึกช่วยจำ) หมวด เลขอ้างอิง
- ยืนยันหมวดครั้งหนึ่ง แอปจำร้าน/ผู้รับนั้นให้ครั้งต่อไป
- เตือนถ้าสลิปซ้ำ (เช็กจากเลขอ้างอิง)

อัปเดต v13 (ปรับให้อ่านสลิป K+ และ ttb)
- อ่านยอดเงินตัวใหญ่ของ ttb ด้วยการตัดแถบตัวเลขมาอ่านแยก
- ถ้าวันที่บนสลิปเพี้ยน ใช้วันที่-เวลาที่ฝังในเลขอ้างอิงแทน
- แยกผู้โอน/ผู้รับตามตำแหน่ง ตัด noise จากพื้นหลังสลิป
- เตือนเมื่ออาจเป็นการโอนเข้าบัญชีตัวเอง

อัปเดต v14 (วันเวลาในชีต)
- ชีตใหม่ชื่อ "รายการละเอียด": วันที่ | เวลา | จ่ายให้ใคร | ค่าอะไร | หมวด | จำนวน | ประเภท | เลขอ้างอิง (เรียงล่าสุดก่อน)
- รายการที่จดเองวันนี้ ระบบใส่เวลาให้อัตโนมัติ
- หลังอัปเดตแอป กด "ส่งข้อมูลทั้งหมดขึ้นชีต" 1 ครั้งเพื่อสร้างชีตใหม่

อัปเดต v15
- งบรายสัปดาห์ (ตั้งค่า > งบแยกหมวดและรายสัปดาห์) + เตือนเมื่อใช้ถึง 80% / เกิน
- สถิติ: สรุปรายสัปดาห์ (เลื่อนดูย้อนหลังได้), กราฟช่วงเวลาที่ใช้เงิน, ร้าน/ผู้รับที่จ่ายบ่อย 10 อันดับ
- หน้าบันทึก: ค้นหา/กรองรายการ (ชื่อ หมวด วันที่ ประเภท ยอด)
- แก้ไขได้ทุกช่องของรายการ (ยอด วันที่ เวลา ผู้รับ รายละเอียด หมวด ประเภท จ่ายหนี้)
- ชีตใหม่ "สรุปรายสัปดาห์" (ซิงก์พร้อมชีตอื่น)
